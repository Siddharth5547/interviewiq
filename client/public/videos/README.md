# InterviewIQ Demo Videos

Place the official product demonstration video in this directory:

- File name: `interviewiq-demo.mp4` (or `demo.mp4`)
- Target resolution: 1920x1080 (16:9 aspect ratio)
- Recommended codec: H.264 / AAC MP4

The `ProductDemoPlayer` component on the About page will automatically detect and stream this video file if present. If no file is detected, the player seamlessly falls back to the interactive 15-scene guided product walkthrough.
